This dashboard connects to a Supabase project for real logins and cloud storage. It's not connected yet — here's how to finish the 10-minute setup (full guide in README.md).

1
Create a free Supabase project.
Go to supabase.com → Start your project → pick a region close to you.
2
Run setup.sql once.
In your project: SQL Editor → paste the whole setup.sql file → Run. This builds the database, logins, and security rules.
3
Create your admin account.
Open this dashboard, go to Create account, sign up, then in Supabase SQL Editor run the line at the bottom of setup.sql with your email to promote yourself to admin.
4
Paste your keys.
In Supabase: Project Settings → API. Copy the Project URL and the anon public key, then edit index.html and paste them in the two marked lines at the top of the script.
5
Upload to GitHub.
Create a repo, push index.html, then Settings → Pages → deploy from the repo. Your dashboard is live.
